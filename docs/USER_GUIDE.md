# 사용 안내

회식 장소를 정하는 사람(이하 **총무**)과 참석하는 사람(**팀원**)이 하는 일을 순서대로 적었습니다.

## 총무

### 1. 부서와 회식 만들기
1. 오른쪽 위 부서 목록에서 우리 팀을 고릅니다. 없으면 **부서별 식탁** 아래 **부서 추가**에 팀 이름을 넣습니다.
2. **새 회식 만들기**를 누르고 회식 이름, 날짜와 시간, 지역을 넣습니다.
   - 지역을 비워 두면 팀원들 출발지의 가운데쯤에서 찾습니다.
   - 날짜가 **90분 안**이면 사장님께 "지금 자리 있나요?"를 묻고, 그보다 먼 날이면 예약 요청으로 확인합니다.

### 2. 팀원 조건 모으기
1. **조건 입력** 메뉴에서 **참석자 추가**에 이름(과 직함)을 넣습니다. 사람마다 개인 링크가 만들어집니다.
2. **공유 링크 복사**를 누르면 모든 사람의 링크가 한 번에 복사됩니다. 단톡방에 붙여 넣으세요.
3. 팀원이 입력하면 표의 상태가 **입력 완료**로 바뀝니다. 대신 넣어 줄 때는 이름 옆 연필 아이콘을 누르세요.

### 3. 후보 보기
1. **추천 후보 보기**를 누릅니다.
2. **조건 정리**에 꼭 지킬 조건(필수), 맞춰 볼 조건(선호), 부딪히는 조건(충돌)이 나옵니다.
   - 충돌 옆 **완화해보기**를 누르면 그 기준으로 다시 찾고, 후보 수가 어떻게 바뀌는지 보여 줍니다.
3. **후보 비교**에서 가게마다 팀원별 이동 시간, 조건 충족 여부, 추천 이유, 메뉴 평균 가격을 봅니다.
   - 25분이 넘는 이동은 붉게 표시됩니다.
   - **사진 · 메뉴 · 위치**에서 사진과 메뉴를 보고, 지도로 열거나 위치를 공유할 수 있습니다.

### 4. 확인하고 예약하기
1. 후보 위의 **사장님께 지금 자리 묻기** 또는 **예약 요청 준비**를 누릅니다.
2. 사장님이 "가능"이라고 답했거나 예약할 차례가 되면 확인 칸이 열립니다. 다른 가게로 바꾸려면 카드의 **이곳으로 예약**을 누르세요.
3. 예약자 연락처를 넣고 **예약 요청 보내기**를 누릅니다.
   - **거절되면 다음 가게로 바로**를 켜 두면, 거절당해도 다음 순위로 자동으로 다시 요청합니다.
   - 연락처는 이번 요청에만 쓰고 저장하지 않습니다.
4. 확정되면 **단톡방 공지**가 만들어집니다. **공지 복사**로 붙여 넣으세요.

### 5. 확정 뒤
- **인원 변경**: 바뀐 인원을 넣고 **가게에 다시 확인**을 누르면, 확정한 가게부터 다시 묻고 안 되면 다른 후보를 찾습니다.
- **2차**: **1차 근처 2차 찾기**를 누르면 근처에서 지금 들어갈 수 있는 곳을 찾습니다.

### 6. 다녀와서
1. 별점, 1인 지출, **다시 가고 싶어요** 여부를 넣고 **기록 저장**을 누릅니다.
2. **모임 기억**에 쌓이고, 다음 회식부터 추천에 반영됩니다. 만족했던 가격대는 점수에 들어가고, 다시 안 가겠다고 한 곳은 빠집니다.
3. **초안 만들기**를 누르면 기록으로 후기 초안을 써 줍니다(기록에 없는 내용은 쓰지 않습니다).

### 작업 로그
위쪽 **작업 로그** 메뉴에서 에이전트가 무엇을 했는지 시간순으로 볼 수 있습니다. 어떤 가게가 왜 빠졌는지, 사장님이 언제 답했는지가 남습니다.

## 팀원

1. 단톡방에 올라온 내 이름 옆 링크를 엽니다. 로그인은 필요 없습니다.
2. 출발하는 역, 1인 예산, 식단, 알레르기, 먹고 싶은 것, 원하는 분위기를 적고 **저장하기**를 누릅니다.
3. 조건이 바뀌면 같은 링크로 다시 들어와 고치면 됩니다.

> 링크를 아는 사람은 누구나 그 내용을 고칠 수 있습니다. 링크는 팀 단톡방에만 공유하세요.

## 공개 데모에서

공개 데모 주소에서는 누구나 같은 데이터를 보고 고칠 수 있습니다. **실제 이름이나 연락처는 넣지 마세요.** 예약·문의는 모두 시뮬레이션이라 실제 가게에는 아무것도 가지 않습니다.
