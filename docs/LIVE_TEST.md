## 2단계. 실제 요청 (사장님 휴대폰으로 감 — 사장님과 미리 약속한 뒤에만)
```
YUMI_ACTIONS=live
YUMI_LIVE=1
DEMO_SCRIPT=0
```
- 화면 상단 배지가 빨간색 "실제 요청"으로 바뀌는지 확인
- "실제로 보내는 것에 동의" 체크해야 버튼이 동작
- 실매장 테스트는 이 가게 한 곳에만 보내고 다른 가게로 넘어가지 않음 (auto_fallback 꺼짐)
- 지금 자리 문의는 방문 시간이 90분 안일 때만, 그 밖은 예약 요청으로 확인
- 취소 API는 없음. 확정되면 예약자 문자로 온 취소 링크로 취소
- 끝나면 바로 YUMI_ACTIONS=simulate, YUMI_LIVE=0 으로 되돌리기
